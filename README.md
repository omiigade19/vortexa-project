# LearnLoop AI – Adaptive AI Tutor

**Problem Statement:** E-01  
**Event:** VORTEXA 3.0

## About Project
LearnLoop AI is an AI-based learning website that helps students understand concepts, identify mistakes, and improve their learning through personalized questions and explanations.

## Features
- Simple explanations of concepts.
- Detects students' common mistakes.
- Provides personalized feedback and questions.
- Tracks student progress and concept mastery.
- Compares pre-test and post-test scores.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python (Flask)
- AI-based answer analysis

## How to Run
1. Clone or download the repository.
2. Install the required Python packages.
3. Run the application using `python app.py`.
4. Open the local website in your browser.

## Expected Outcome
Help students learn better by identifying their mistakes and providing personalized guidance.
